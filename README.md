# 🐄 Smart Cattle Health Monitoring System

An IoT-based embedded system that continuously monitors cattle health using physiological and environmental sensors.

---

## Features

Body Temperature Monitoring
Heart Rate Monitoring
Blood Oxygen (SpO₂)
Activity Detection
GPS Tracking
Environmental Monitoring
Web Dashboard
Health Status Prediction

---

## Hardware

- ESP8266 NodeMCU
- MAX30102
- DS18B20
- MPU6050
- DHT11
- GPS NEO-6M

---

## Software

- Arduino IDE
- Embedded C++
- HTML
- CSS
- JavaScript

---

## Communication

- I²C
- UART
- OneWire
- Wi-Fi
